# QR_Code_Generator

Application web pour générer des QR Codes, développée avec Vue.js et Vuetify.  
Projet personnel visant à expérimenter les composants UI modernes et la génération dynamique de QR Codes.

---

## 🚀 Fonctionnalités

- Génération de QR Codes à partir de texte ou URL
- Interface utilisateur fluide avec Vuetify
- Aperçu en temps réel du QR Code
- Copie et téléchargement possibles (si implémenté)

---

## 🛠️ Stack technique

- Vue.js
- Vuetify (UI framework)
- JavaScript
